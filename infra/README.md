# Инфраструктура

Каталог для будущих Dockerfile, локальной конфигурации PostgreSQL и инструкций развёртывания. Конфигурация появится вместе с запускаемыми приложениями; Redis пока не требуется.

Секреты задаются окружением и не сохраняются в репозитории. Шаблоны .env.example добавляются вместе с кодом, который читает соответствующие переменные.
