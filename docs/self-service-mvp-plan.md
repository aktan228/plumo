# План самостоятельного MVP

План из согласованного обсуждения регистрации: клиент проходит регистрацию → бизнес → настройки → тест → кабинет → Telegram.

1. Регистрация: пользователь, бизнес и черновик одной транзакцией — реализовано.
2. Доступ: подтверждение почты, повторное письмо, восстановление и сессии — реализовано; для реальной отправки нужен Resend на Render.
3. Мастер: гостевой вход, перенос в аккаунт, автосохранение и восстановление — реализовано.
4. Бизнес и агент: публикация текстов/FAQ/TXT/MD в базу своего бизнеса; параметры влияют на ядро — реализовано. [Подробности](business-agent-settings.md).
5. Настоящий тестовый чат: запросы к ядру, отдельная история тестов, ошибки/повторы, лимиты сообщений и расходов — реализовано. [Подробности](agent-test-chat.md).
6. Самостоятельный Telegram: ввод токена клиентом, проверка, webhook, зашифрованное хранение, проверочное сообщение и включение ответов — следующий этап.
7. Кабинет: статусы готовности бизнеса/материалов/теста/канала, остальные разделы soon — дальнейший этап.
8. Полный прогон нового клиента на Python 3.12 и Vercel/Render/Supabase, две компании и изоляция — финальная приёмка после пунктов 5–7.

Платежи, роли сотрудников, Google OAuth и самостоятельный Instagram не входят в эту последовательность первой демонстрации.
