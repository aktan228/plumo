## Демонстрационный поток

1. Посетитель открывает лендинг Next.js.
2. Демо-чат отправляет сообщение в FastAPI.
3. Backend собирает контекст из вымышленных данных, вызывает модель и выполняет разрешённые действия.
4. История и расходы сохраняются в PostgreSQL.
5. Ответ возвращается в чат.

Форма заявки на пилот отдельно отправляет контактные данные в FastAPI для сохранения. При реализации нужны валидация и ограничение частоты обращений. Ключи моделей доступны только backend.

## Ближайшие этапы

1. Инициализировать Next.js и FastAPI с закреплёнными зависимостями и командами запуска.
2. Создать дизайн лендинга и адаптивные секции.
3. Подключить PostgreSQL и миграции, реализовать сохранение заявок.
4. Создать вымышленную базу знаний и рабочее демо через API модели.
5. Проверить основные сценарии, ошибки API, изоляцию данных и мобильный интерфейс.

Никакие аккаунты провайдеров, платные ресурсы и публичный хостинг этой структурой не создаются.
