# DB-07: клиенты

Реализовано 2 ноября 2026. В кабинете доступен раздел `/dashboard#customers`. Миграция не требуется; API и frontend выпускаются вместе.

`GET /api/v1/customers` возвращает клиентов бизнеса оператора. Поиск по имени/handle диалога, номеру из канала, непроверенному номеру обратного звонка и внешнему контакту выполняется в SQL по всему бизнесу. Поддерживаются фильтр канала и курсорная пагинация (по умолчанию 30, максимум 100). Порядок: дата создания клиента и ID, новые сначала. `%`, `_` и `\` трактуются как символы поиска. RU/KY-регистр нормализуется явно, включая PostgreSQL с C-locale.

Имя и handle берутся из последнего доступного диалога с этими полями. Каналы получаются из связей и диалогов своего бизнеса. Общего счётчика всех клиентов нет: интерфейс показывает страницы, не выдавая размер загруженной страницы за общее число.

Карточка получает реальные доступные контакты, язык, потребность, резюме и историю. Последние сообщения ограничены 100; диалоги открываются по существующей защищённой ссылке. Выбор клиента записывается в URL (`?customer=<uuid>#customers`) и сохраняется после обновления/входа. На узком экране доступны карточка и возврат к списку. Запросы прежней карточки/фильтра отменяются; данные с прежним ключом страницы не показываются как новая выдача.

Номер из сообщения подписан как непроверенный. Совпадение этого номера не объединяет карточки; ручное создание, импорт и объединение не добавлялись. Записи с `merged_into_id` не показываются в общем каталоге; существующий доступ к их собственной карточке не менялся.

Сессия оператора определяет business_id. Параметр бизнеса из браузера не пересылается BFF. Поиск, контакты, каналы и история дополнительно ограничиваются бизнесом; повреждённая связь чужого диалога/сообщения с собственным customer_id не раскрывает содержимое. API списка и карточек доступны только для чтения.

Регрессии: стабильные страницы без дублей при одинаковой дате, поиск RU/KY и буквальных спецсимволов, фильтр канала, одинаковый непроверенный номер у отдельных клиентов, другая компания, анонимный запрос, неверные курсоры, повреждённые связи и история. Результаты запусков — в `PLUMO_DASHBOARD_PROGRESS.md` рабочей папки. Визуальная и мобильная приёмка остаются отдельными проверками; эти тесты не подтверждают живую доставку канала.
