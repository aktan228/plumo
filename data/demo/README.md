# Демонстрационные данные

Здесь будут только вымышленные объекты недвижимости, услуги, FAQ и тестовые диалоги. Реальные контакты посетителей лендинга хранятся отдельно в БД.

Не добавлять реальные записи звонков, выгрузки CRM или персональные данные. Демо-объекты должны явно обозначаться как вымышленные.
