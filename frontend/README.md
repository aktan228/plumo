# Frontend Plumo

Целевой стек: Next.js (App Router), TypeScript, Tailwind CSS; shadcn/ui для нужных компонентов. Сейчас создана только структура, приложение и зависимости ещё не инициализированы.

| Каталог | Назначение |
|---|---|
| src/app | Страницы, корневой layout и общие стили |
| src/components/landing | Секции лендинга |
| src/components/ui | Повторно используемые элементы интерфейса |
| src/features/demo | Демо-чат: интерфейс, состояние и обращения к API |
| src/features/pilot-request | Форма заявки на пилот |
| src/lib | Общий HTTP-клиент и вспомогательные функции |
| src/types | Общие типы; контракты API согласуются с FastAPI |
| public/images | Изображения и графика |
| public/fonts | Локальные шрифты при необходимости |
| tests | Проверки пользовательских сценариев |

Бизнес-логика и ключи провайдеров находятся в backend. Браузер не подключается напрямую к PostgreSQL или API моделей.

Сначала реализуем лендинг, демо на вымышленных данных и форму заявки. Функции телефонии показываем только в соответствии с их реальным статусом. Команды запуска будут добавлены при инициализации Next.js.
