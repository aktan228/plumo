# Frontend Plumo

Создан минимальный Next.js (App Router) + TypeScript frontend с Motion. Tailwind CSS и shadcn/ui пока не подключены: текущий хедер оформлен обычным CSS.

## Запуск

Из папки frontend (Node.js 20.9 или новее):

```powershell
npm install
npm run dev
```

Открыть http://localhost:3000. Команда `npm run typecheck` проверяет TypeScript, `npm run build` собирает приложение. Сервер при реализации хедера не запускался.

## Что реализовано

- Логотип пользователя и белая кнопка «Войти» с чёрной рамкой без ссылок FAQ и «Как работает».
- Хедер скрывается вниз по странице и возвращается при прокрутке вверх. У начала страницы всегда виден; мелкие движения игнорируются.
- Анимация Motion отключается при prefers-reduced-motion. Фокус клавиатуры возвращает скрытый хедер.
- Главная пока содержит временный экран и область прокрутки для проверки хедера; полный лендинг не реализован.
- /login, /register, /forgot-password — формы входа, регистрации и восстановления по референсу: округлые поля, переключение видимости пароля, встроенная валидация и белые кнопки с чёрной рамкой. Backend авторизации не подключён: отправка явно сообщает, что данные не отправлены. Пароли нигде не сохраняются.
- Переключение RU/EN в хедере и на страницах авторизации, выбор сохраняется локально. Все текущие тексты переведены. Код ky зарезервирован в src/lib/i18n.tsx, кыргызский пока не переводится и не доступен в переключателе.

| Каталог | Назначение |
|---|---|
| src/app | Страницы, корневой layout и общие стили |
| src/components/landing | Секции лендинга |
| src/components/ui | Повторно используемые элементы интерфейса |
| src/features/demo | Демо-чат: интерфейс, состояние и обращения к API |
| src/features/pilot-request | Форма заявки на пилот |
| src/lib | Общий HTTP-клиент и вспомогательные функции |
| src/types | Общие типы; контракты API согласуются с FastAPI |
| public/images | Изображения и графика |
| public/fonts | Локальные шрифты при необходимости |
| tests | Проверки пользовательских сценариев |

Бизнес-логика и ключи провайдеров находятся в backend. Браузер не подключается напрямую к PostgreSQL или API моделей.

Далее реализуем лендинг, демо на вымышленных данных и форму заявки. Функции телефонии показываем только в соответствии с их реальным статусом.
