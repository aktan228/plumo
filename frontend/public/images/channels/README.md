# Логотипы каналов

Локальные файлы для карточек интеграций и мастера настройки. Логотипы показываются без изменения рисунка и цвета.

- WhatsApp Business: оригинальная иконка WhatsApp Inc. из Google CDN — https://lh3.googleusercontent.com/JgGYz6b1TBsreBWZ9W9mfPQWMguIhCA3BiR7nKgE2miAzL1drW4mLL5_q0exDjtTDRg=s180. Источник и автор указаны также на https://commons.wikimedia.org/wiki/File:WhatsApp_Business_icon.png.
- Telegram: SVG с официального сайта — https://telegram.org/img/t_logo.svg. Информация об использовании: https://telegram.org/press#telegram-logos.
- Instagram: цветной SVG — https://upload.wikimedia.org/wikipedia/commons/e/e7/Instagram_logo_2016.svg. Источник и условия: https://commons.wikimedia.org/wiki/File:Instagram_logo_2016.svg (PD-textlogo, товарный знак Instagram).

Товарные знаки принадлежат соответствующим владельцам; использование обозначает каналы интеграции.
