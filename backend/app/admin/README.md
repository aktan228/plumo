# Внутренняя админка Plumo

Каркас панели сотрудников для ручного подключения пилотных компаний. Это модуль одного backend, а не отдельный сервис и не личный кабинет клиента.

- `router.py` — сборка административных маршрутов.
- `dependencies.py` — доступ сотрудников и проверка разрешённой компании.
- `views/` — компании, база знаний, диалоги и заявки на пилот.
- `templates/` — будущие HTML-шаблоны панели.
- `static/` — будущие стили и скрипты панели.

Панель, авторизация и обработчики пока не реализованы. Библиотека админки не выбрана. До подключения маршрутов нужны проверка прав, изоляция по `business_id` и журналирование изменений. Админка должна использовать общие сервисы и репозитории, а не дублировать бизнес-логику.
