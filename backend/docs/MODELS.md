# Какую модель брать

Коротко: **большая модель — Claude Haiku 5.5 через OpenRouter (`anthropic/claude-haiku-5.5`, thinking выключен), запасная — Haiku 4.5.** Решение от 9 октября, замеры в конце файла. Gemini 3.8 Flash медленнее (3.5–6 с) и в 6 раз дороже. Дальше устаревший текст про Gemini оставлен для истории.

Прежнее решение (устарело): коротко: **большая модель — Gemini 3.8 Flash, запасные — 3.7 Flash и 3.1 Flash-Lite, вызываются напрямую через Google AI Studio.** Малой модели пока нет: её реплики уходят большой (`SMALL_MODEL_PROVIDER=none`). OpenRouter остаётся стендом для сравнения моделей и запасным провайдером.

**Gemini 2.5 Flash и 2.5 Flash-Lite отключаются 20 октября 2026** (дата из каталога OpenRouter на 9 октября). На них ничего не строим.

Откуда задержка (замер 9 октября, 3.8 Flash через OpenRouter, потоковый режим):

| --- | --- |
| Сеть до OpenRouter / до Google из Бишкека | 0.01–0.04 с / 0.1–0.3 с |
| Первый символ на запрос «скажи привет» (почти пустой промпт) | **3.6–4.9 с** |

| Остаток ответа после первого символа | ~1 с |

Вывод: почти всё время — ожидание первого токена на стороне модели и провайдера. Промпт, JSON-режим и сеть почти не влияют, поэтому сокращать промпт бесполезно. Мы и так платили за модель (OpenRouter, не бесплатный tier), так что **оплата задержку не уберёт**. Платный tier Google снимает лимиты (наш прогон упёрся в 429) и запрет на использование данных, но скорость модели остаётся той же.

Что делать:
1. Замерить прямой Gemini API (`python -m app.ping_llm --provider gemini_big --repeat 3`) — нужен `GEMINI_API_KEY`.
2. Замерить Claude Haiku / Sonnet тем же способом — нужен `ANTHROPIC_API_KEY`.
3. В звонке закрыть паузу живой фразой: soft timeout ElevenLabs ~1.5 с, «Так, секунду, смотрю…» (`VOICE.md`).
4. Если прямой Gemini даст те же 3–5 с, а Claude быстрее — сравнить по стенду `app.bench` и выбирать по качеству и задержке вместе.

## Thinking

Мышление оплачивается как выход и задерживает речь.

- Gemini 3 его **не выключает**: `reasoning_effort: "none"` даёт HTTP 400 (проверено). Ставим `minimal` — это значение по умолчанию.
- Для 2.5 Flash ставится `none`.
- Переопределить: `LLM_REASONING_EFFORT=low`.
- Для Google напрямую параметр уходит как `reasoning_effort`, для OpenRouter — как `reasoning.effort`.

## Устойчивость

- 429, 5xx и сетевые ошибки: до `LLM_MAX_RETRIES=2` повторов с экспоненциальной паузой. Всё укладывается в бюджет реплики.
- 404 или «model no longer available»: переход на следующую модель из `*_FALLBACK_MODELS`. Переход постоянный, пока процесс не перезапущен; в лог пишется ошибка `llm model retired, switching`.
- Неверный ключ, нет кредитов, отключены все модели: клиент получает готовую фразу, менеджер получает передачу `model_unavailable`. Ответа 503 нет.

## Кэш

Неявный кэш Gemini даёт скидку на повторяющееся начало промпта. Поэтому промпт собран так: сначала неизменная часть (инструкции, формат ответа, карточка бизнеса), потом то, что меняется от реплики к реплике (найденные объекты, клиент, переписка). Если провайдер отдаёт `prompt_tokens_details.cached_tokens`, кэшированные токены считаются по цене кэша.

## Почему напрямую, а не через OpenRouter

| | Google AI Studio | OpenRouter |
| --- | --- | --- |
| Комиссия | 0 | 5.5% при пополнении (минимум $0.80) |
| Бесплатный лимит | есть, для разработки | нет (кроме `openrouter/free`) |
| Данные клиентов | платный тариф: Google не использует данные для обучения | зависит от провайдера |
| Смена модели | только Gemini | любая модель одной строкой |

На бесплатном тарифе AI Studio Google может использовать запросы для улучшения своих продуктов. Для демо на вымышленных данных это допустимо. **Для пилота с реальными клиентами — только платный tier.**

## Как переключить

```
AI_MODE=production
SMALL_MODEL_PROVIDER=none
BIG_MODEL_PROVIDER=gemini_big
GEMINI_API_KEY=...            # https://aistudio.google.com/apikey
```

Claude: `BIG_MODEL_PROVIDER=anthropic_big` (Sonnet 5.5) или `anthropic_small` (Haiku 5.5) + `ANTHROPIC_API_KEY`, адаптер `infrastructure/ai/anthropic_llm.py`. OpenRouter: `BIG_MODEL_PROVIDER=openrouter_big`, модели в `OPENROUTER_*_MODEL`. Любой OpenAI-совместимый API: `openai_compat_big` + `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_*_MODEL`.

## Как сравнить модели самим

```powershell
python -m app.ping_llm --provider openrouter_big --model google/gemini-3.1-flash-lite --repeat 3
python -m app.eval_live --provider gemini
python -m app.eval_live --provider openrouter --small google/gemini-3.1-flash-lite --big google/gemini-3.8-flash
```

`ping_llm` — одна реплика на настоящем промпте, без базы: модель, задержка, токены, цена. `eval_live` — 10 реплик (чат → звонок → кыргызский → посторонняя тема) через всё ядро.

Что стоит за разницей в 2 ответа: провалы Haiku — ложные срабатывания проверок (фраза «подземной парковки нет» ловится как обещание парковки, верная комиссия продавца, отказ «80 000 в данных нет»). У Gemini реальный провал: в голосе «перевожу вас на менеджера, оставайтесь на линии» (соединения нет). В живом диалоге Gemini ещё выдумал «менеджер встретит вас у дома» и предложил «соединить с живым менеджером». Handoff решает ядро по сигналам (`evaluate_handoff`), а не флаг модели, поэтому проверки `handoff_required` в бенче для выбора модели не учитываются.

Не проверено: кыргызский с носителем, повтор на реальных записях звонков.
