# Какую модель брать

Коротко: **Gemini 2.5 Flash-Lite для малой модели, Gemini 2.5 Flash для большой, напрямую через Google AI Studio.** OpenRouter оставляем как удобный стенд для сравнения моделей.

## Цены и замеры

Реплика Plumo — около 1 650 входных токенов (инструкции, данные агентства, история) и 60 выходных. Цены — USD за 1M токенов, по данным на осень 2026: перед пилотом сверить с официальными страницами.

| Модель | Вход | Выход | ≈ за реплику | Кыргызский | Заметки |
| --- | --- | --- | --- | --- | --- |
| **Gemini 2.5 Flash-Lite** | 0.10 | 0.40 | **$0.00019** (замер) | хороший | p50 ≈ 0.7 с в нашем прогоне. Тон живой, факты держит |
| **Gemini 2.5 Flash** | 0.30 | 2.50 | ~$0.0007 | хороший | умнее на возражениях и сравнениях. Thinking выключаем — без него быстрее и дешевле |
| Gemini 3.1 Flash-Lite | 0.25 | 1.50 | ~$0.0005 | — | новее, дороже 2.5 Flash-Lite. Сравнить через `eval_live` |
| Gemini 3 Flash | 0.50 | 3.00 | ~$0.001 | — | кандидат на большую модель, если 2.5 Flash не хватит |
| GPT-5 nano | 0.05 | 0.40 | ~$0.0001 + reasoning | слабый | reasoning-модель: задержка выше, для голоса плохо |
| DeepSeek V3.2 | 0.28 | 0.42 | ~$0.0005 | слабый | серверы далеко, задержка выше |

Диалог из 8–10 реплик на Flash-Lite стоит около $0.002. Если роутер шлёт треть реплик в Flash, выходит около $0.003. Плюс голос ElevenLabs ~$0.08/мин и сообщения WhatsApp.

## Почему Gemini

- Лучшая цена за качество на русском и кыргызском среди дешёвых моделей. В прогоне Flash-Lite ответил по-кыргызски с верной ценой.
- Неявное кеширование: начало промпта (инструкции и данные агентства) одинаковое у всех реплик, Gemini даёт на повторяющийся префикс скидку сам.
- OpenAI-совместимый API: подключается тем же адаптером, что и OpenRouter.

## Почему напрямую, а не через OpenRouter

| | Google AI Studio | OpenRouter |
| --- | --- | --- |
| Комиссия | 0 | 5.5% при пополнении (минимум $0.80) |
| Бесплатный лимит | есть, для разработки | нет (кроме `openrouter/free`) |
| Данные клиентов | платный тариф: Google не использует данные для обучения | зависит от провайдера |
| Смена модели | только Gemini | любая модель одной строкой |

Важно: на бесплатном тарифе AI Studio Google может использовать запросы для улучшения своих продуктов. Для пилота с реальными клиентами включаем биллинг (платный Tier 1).

## Как переключить

```
AI_MODE=production
SMALL_MODEL_PROVIDER=gemini_small
BIG_MODEL_PROVIDER=gemini_big
GEMINI_API_KEY=...            # https://aistudio.google.com/apikey
```

OpenRouter: `openrouter_small` / `openrouter_big` + `OPENROUTER_*_MODEL`. Любой OpenAI-совместимый API: `openai_compat_small` / `_big` + `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_*_MODEL`.

## Как сравнить модели самим

```powershell
python -m app.eval_live --provider openrouter --small google/gemini-2.5-flash-lite --big google/gemini-2.5-flash
python -m app.eval_live --provider gemini
python -m app.eval_live --provider openai_compat --small deepseek-chat --big deepseek-chat
```

Прогон: 10 реплик (чат → звонок → кыргызский → посторонняя тема) через всё ядро. По каждой реплике печатаются ответ, маршрут, модель, задержка, стоимость, передача и причина, по которой ядро заменило ответ модели. Сравнивать: живость тона, верность фактов, p50 задержки, цену за реплику.
